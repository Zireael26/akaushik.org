Never silently discard unresolved facts. Here, 2,000 policy tokens, 1,500 task tokens, and 4,000 required tool-result tokens are protected. When they cannot fit with the output reserve, this allocator rejects the call. In production, fetch referenced artifacts, summarize under a validated contract, or choose an appropriate context limit.


Assumptions: simple token counts; no tokenizer overhead; fixed mandatory sizes; divisible optional payloads.     05
    Reliability depends on the question.
    

    “At least one of five attempts works” and “all five attempts work” measure different things. Correlated failures change both, even when the success probability of one attempt stays fixed.
    

    

    

    

    

    

    Try k = 1: both models must give p. Then increase k. Finally set q = 0 and confirm the independent and mixture results coincide.
    

    Illustrative inputs only. There are no empirical success rates in this experiment. Repeated attempts help only if your selector or verifier can identify a valid result.
    

    

    

    Independent attemptsShared-failure mixture
    


    CriterionIndependentMixture
    

    Independent Bernoulli attempts
    pass@k = 1 − (1 − p)k
    pass^k = pk
    Shared-failure mixture, same marginal p
    s = p / (1 − q)
    pass@k = (1 − q) · [1 − (1 − s)k]
    pass^k = (1 − q) · sk
    

    

    

    

    Mixture definition: with probability q, a shared event makes every attempt fail; otherwise attempts are independent Bernoulli(s). Holding marginal p fixed requires s = p/(1−q) and 0 ≤ q ≤ 1−p. At p = 0, q = 1, all attempts fail and the conditional success rate is undefined. This is one positive-correlation model, not a general model of agent errors.
    

    Evaluation transfer: report the task distribution, trial count, verifier, uncertainty, and costs. These formulas describe an assumed probability model. For an empirical candidate set of n samples with c successes, the standard combinatorial pass@k estimator is 1 − C(n−c,k) / C(n,k) for n ≥ k; plugging an estimated success rate into the independent formula is not the same estimator. This companion uses pass^k for the probability all k runs succeed.
