# Runbook 008 — production deploy of demo.akaushik.org

Everything below is ready. Nothing here has been run against production:
the production deploy and the client accounts need the operator's explicit go.

Run from: `apps/demo`.

## 0. Already done
- demo-prod-auth / demo-prod-chat D1 created and migrated (ids in wrangler.jsonc).
- Preview verified end to end against VeriCite prod v5 (every suggested question answered or declined as intended; citations open inline at #page=N).

## 1. Deploy the Worker first (the secrets need the Worker to exist)
    pnpm build:worker
    env -u CLOUDFLARE_API_TOKEN pnpm exec wrangler deploy --env production

## 2. Secrets (all piped via stdin; nothing lands in a file or the shell history)
The values of CHANNEL_ID, DEMO_TITLE, DEMO_SUBTITLE and the path of
SUGGESTIONS_FILE come from the upstream operator and are never committed
(the preview holds the same values). Export them in the shell first.
    openssl rand -hex 32 | tr -d '\n' | env -u CLOUDFLARE_API_TOKEN pnpm exec wrangler secret put BA_SECRET --env production
    printf '%s' "$CHANNEL_ID" | env -u CLOUDFLARE_API_TOKEN pnpm exec wrangler secret put VERICITE_CHANNEL_ID --env production
    printf '%s' "$DEMO_TITLE" | env -u CLOUDFLARE_API_TOKEN pnpm exec wrangler secret put DEMO_TITLE --env production
    printf '%s' "$DEMO_SUBTITLE" | env -u CLOUDFLARE_API_TOKEN pnpm exec wrangler secret put DEMO_SUBTITLE --env production
    env -u CLOUDFLARE_API_TOKEN pnpm exec wrangler secret put DEMO_SUGGESTIONS --env production < "$SUGGESTIONS_FILE"
    # Operator: copy the pk_ key to the clipboard, then:
    pbpaste | tr -d '\r\n\t ' | env -u CLOUDFLARE_API_TOKEN pnpm exec wrangler secret put VERICITE_API_KEY --env production

## 3. Viewer accounts (operator picks usernames: 3-30 of letters, digits, _ or .)
Write a 0600 JSON file (array of {email, username, password, name}), e.g. with
random passwords generated by the operator, then:
    READER_CREDENTIAL_FILE=<file> DEMO_AUTH_DB=demo-prod-auth DEMO_WRANGLER_TARGET=production \
      env -u CLOUDFLARE_API_TOKEN node scripts/demo-accounts.mjs create

## 4. Verify
    curl -s -o /dev/null -w '%{http_code}\n' https://demo.akaushik.org/          # 200, generic "Private demo"
    curl -s https://demo.akaushik.org/ | grep -c '<h1[^>]*>Private demo'        # 1: no branding before sign-in
    curl -s -o /dev/null -w '%{http_code}\n' -X POST -H 'origin: https://demo.akaushik.org' -H 'content-type: application/json' -d '{"query":"hi"}' https://demo.akaushik.org/api/chat   # 401
Then sign in and run two suggestions plus one decline.

## Rollback
    env -u CLOUDFLARE_API_TOKEN pnpm exec wrangler rollback --env production
or remove the demo.akaushik.org custom domain. Revoking the pk_ key stops all answers.
