## P1 — High

### 1. Draft/unpublished content leaks in production via Markdown + OG-image routes
**Root cause, 7 findings across 4 slices (app-routes, content-mdx, security, sweep).**
`app/writing/[slug]/md/route.ts` and `app/work/[slug]/md/route.ts` call `getPost()` and return `post.content` with **no `fm.draft` gate** — unlike the HTML page (`app/writing/[slug]/page.tsx:45`) which does `if (fm.draft === true && NODE_ENV === 'production') notFound()`. `getPost()` (`lib/content.ts:143-156`) never filters drafts; only `getAllPosts()` does. Neither `/md` route sets `dynamicParams = false`, so draft slugs render on-demand in prod.
- Leaks: `content/writing/_test-draft.mdx` (dek literally "hidden"), `native-git-hooks-for-non-node`, `process-gate-stack-profiles`, `renaming-projects`, and `content/case-studies/clusterbid.mdx` (contains `role: PLACEHOLDER — Abhishek to confirm`).
- Reachable via `/writing/<slug>.md`, `/work/<slug>.md` (proxy Pattern B) and `Accept: text/markdown` (Pattern A) — the exact agent/crawler surface the site was built for. Each response tagged **`X-Robots-Tag: index, follow`**.
- Same missing guard in both `opengraph-image.tsx` handlers (`app/work/[slug]/opengraph-image.tsx:18`, writing equivalent) → draft titles/deks rendered into cacheable public images.
- **Directly contradicts** CLAUDE.md editorial-approval requirement + spec 001 non-goal "don't publish drafts without approval."
**Fix:** Port the `page.tsx` draft guard into both `md/route.ts` and both `opengraph-image.tsx` handlers (or route them through the draft-aware slug set), returning `notFound()`.

### 2. `getPost()` interpolates caller slug into file path unsanitized (path traversal)
`lib/content.ts:147` — `join(contentDir(type), \`${slug}.mdx\`)` with no validation. Dynamic route param can escape the intended content-type directory (blast radius constrained to `.mdx` files reachable from `content/` via relative traversal). Compounds #1 by crossing content-type boundaries.
**Fix:** Allowlist `slug` (`^[a-z0-9-]+$`) before use, or `path.resolve` + assert result stays within `contentDir(type)`.

## P2 — Medium

### 3. CI never runs the unit test suite; coverage thresholds enforced nowhere (false-green)
- `.github/workflows/ci.yml:15` verify job runs lint + build but **not `pnpm test`**. Branch protection on main is unconfigured (404), so vitest is only enforced by local `.husky/pre-push` — which never fires on PRs merged via GitHub UI/API. A green PR can ship a `lib/*.test.ts` regression.
- `vitest.config.ts:29` — 75/55/75 coverage thresholds (documented in CLAUDE.md as a real gate) run in no CI/pre-push step. Coverage can silently drop to 0%.
**Fix:** Add `pnpm test:coverage` step to `ci.yml`, or wire `PROCESS_GATE_COVERAGE_CMD` in `local.config.sh`.

### 4. Per-page OpenGraph metadata missing → every work/writing page inherits homepage OG
`openGraph` is declared exactly once sitewide (`app/layout.tsx:53-60`, `url: CANONICAL_ORIGIN` + homepage title/desc). `generateMetadata`/`metadata` in work/[slug], writing/[slug], /work, /writing set `title`/`description`/`canonical` but never `openGraph`. Under Next.js shallow per-field merge, they inherit the homepage's og:title/og:description/**og:url=bare domain** verbatim — contradicting their own per-page `rel=canonical`. Sharing any case-study/post link unfurls with generic homepage copy + wrong URL (per-route OG *image* is correct → mismatched card).
**Fix:** Add explicit `openGraph: { url: canonical(...), title, description }` (+ `twitter`) to each export.

### 5. Vacuous / false-green e2e + accessibility gates
- `e2e/canvas.spec.ts:66` reduced-motion canvas-hidden test: only conditional assertion is dead code; unconditional assertion targets the permanently-disabled crane. Cannot fail if the canvas regressed to visible under reduced-motion. (Same class: `:86` `[data-motion="off"]` test races an unmount → assertion is dead under observed timing.)
- `.github/workflows/lighthouse.yml:79` Axe-core scan still has `continue-on-error: true` past its documented arming condition (the WCAG `home.spec.ts` test is live + passing) → can never fail regardless of violations.
- Stale comment `e2e/home.spec.ts:48-54` claims the WCAG gate is `fixme`'d/disabled; it's actually live (re-armed by PR #78). Misleads readers into thinking the gate is inert.
**Fix:** Make canvas assertions deterministic (`toHaveCount(0)`); remove `continue-on-error` from the armed Axe step; delete the stale comment.

## P3 — Low (correctness, hygiene, defense-in-depth)

### lib correctness (mostly latent; #6b active on shipped content)
- **6a** `lib/dates.ts:12` — invalid calendar dates (Feb 30) roll over via `new Date()` → wrong month silently, no fallback to raw input. Latent (all 15 content dates well-formed) but unvalidated.
- **6b** `lib/reading-time.ts:13` — hyphen-strip splits hyphenated compound words → **inflates word count / reading time on currently-shipped content** (one post already shows +1 min). *Active bug.*
- **6c** `lib/reading-time.ts:12` — unanchored HTML-tag strip: a bare `<` (comparison / generic syntax in prose) swallows text to next `>`, deleting real words from the count. Latent for a programming-topics site.
- **6d** `lib/content.ts:83` — inline-array frontmatter split on every comma, no quote-awareness → quoted item with internal comma corrupts. Latent (current `stack:` arrays are comma-free).

### 7. No CSP / X-Frame-Options / HSTS anywhere in active source
`proxy.ts:76` `buildResponseHeaders()` sets `X-Content-Type-Options`, `Referrer-Policy`, `X-Robots-Tag` but no CSP/framing/transport headers; `next.config.ts` `headers()` only covers `/.well-known/*`. No XSS defense-in-depth (site uses `dangerouslySetInnerHTML` in `components/seo/JsonLdScript.tsx` — currently safely escaped — plus MDX), no clickjacking protection (relevant given iframe edit-mode).
**Fix:** Conservative CSP (`default-src 'self'` + known Cloudflare/font origins) + `X-Frame-Options: DENY`.

### 8. Sitemap `lastModified` = build timestamp, not post date
`app/sitemap.ts:32` uses the single request-time `now` for every writing/case-study entry, discarding available `frontmatter.date`. Google warns against lastmod=generation-time; can make search engines distrust the signal.
**Fix:** Carry `frontmatter.date` per entry; add a `lastModified` field for case studies.

### 9. Three.js resource hygiene (`components/scene/AgentGraph.tsx`)
- `:361` cleanup calls `dispose()` but not `forceContextLoss()` → orphaned WebGL contexts can accumulate toward the browser per-page cap under Fast-Refresh / repeated edit-mode motion toggles.
- `:127` DPR read once at mount, never re-applied → blurred/oversampled canvas when window moves between standard and HiDPI displays mid-session.

### 10. Dead code / drift / false public claims
- `content/case-studies/neev.mdx:10` (+3 others) — `reel` frontmatter field is **dead**: nothing reads it, paths point at no real files. Editors editing `reel:` see no effect.
- `package.json:32` — `clsx` + `tailwind-merge` declared as prod deps, **zero usages** in tracked source.
- `scripts/fetch-github-stats.mjs:143` — `includesPrivate: true` hardcoded in public `stats.json` regardless of which token ran; if `GH_STATS_TOKEN` expires it silently falls back to public-only but still asserts `true` — a false claim in public data.
- `next.config.ts:19` (4 comments) — still reference the deleted `middleware.ts` after the proxy migration; contradicts spec 001's own "docs reflect proxy convention" criterion.
